# Datos sintéticos AT-MORT-001

Este directorio está reservado exclusivamente para datos artificiales destinados a pruebas de software, contratos, integración y CI.

Reglas obligatorias:
- todo registro debe incluir `synthetic=true`;
- no representan peces, centros ni eventos reales;
- no pueden usarse para estimar eficacia, seguridad, causalidad o desempeño biológico;
- no constituyen validación del modelo;
- deben mantenerse separados de cualquier dataset observacional real.
